# Logotipos proporcionales en Header y App Shell

[Header](https://www.figma.com/design/yZsIpXywybsPDytjolwcP4/AI-Blueheart-DS?node-id=90-439) expone **Logotipo** y **Altura**. En [App Shell](https://www.figma.com/design/yZsIpXywybsPDytjolwcP4/AI-Blueheart-DS?node-id=105-7), abre **Header** para cambiar estas propiedades. Hay 75 marcas y formatos oficiales en los tres tamaños de 40, 44 y 48 px. Cada ancho es proporcional al arte original. Los maestros de Logos tienen bloqueo de relación de aspecto.
