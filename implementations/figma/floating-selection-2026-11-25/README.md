# Floating Actions · Alcance de selección

En [Floating Actions](https://www.figma.com/design/yZsIpXywybsPDytjolwcP4/AI-Blueheart-DS?node-id=122-6), usa **Alcance de selección** y su propiedad **Menu**. El menú ofrece la página actual y todo el histórico seleccionado. Las filas muestran conteo y contexto. General actions conserva el Slot de acciones. En [Dot](https://www.figma.com/design/yZsIpXywybsPDytjolwcP4/AI-Blueheart-DS?node-id=32-33), usa count-multi al editar Count con dos o más dígitos.
