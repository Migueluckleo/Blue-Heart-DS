# PAGINATION-0011.0.0

### REQ-ANATOMY

Dos variantes reales default y compact. Default contiene Range opcional derivado, Pages nativo y Rows per page; compact conserva Left, Page label y Right. No crear una variante por página, cantidad de resultados o tamaño de dataset. Los ejemplos son composiciones del consumidor.

### REQ-API

El responsable adopta completar la descripción. Exponer Pages como SLOT editable y Range TEXT/Show range BOOLEAN false y Show rows per page BOOLEAN true, aplicables a default; Page label TEXT se aplica a compact y conserva inicialmente Page 5 of 12. El rango inicial1–20 de240 permanece oculto y el selector muestra20. Guardar keys reales y matriz de aplicabilidad; no afirmar que propiedades exclusivas de default cambian compact.

### REQ-COMPOSITION

PAGINATION-ITEM-001@1.0.0 gobierna todos los números/flechas/ellipsis. INPUT-001@2.0.1 small/filled/default, sin label/helper/tooltip/badge y con CaretDown oficial, es el disparador de Rows per page, ancho88 gobernado por token del padre. Badge queda transitivo del Input aun oculto. No replicar sus tokens, dibujar otro input ni crear Select temporal. Opciones20/50/100 y su apertura son del host o de un Dropdown menu oficial en muestra.

### REQ-SLOT

Pages es Slot horizontal HUG, gap4, mínimo1 y sin máximo de muestra; solo acepta instancias de Pagination item. Conservar referencias y permitir insertar, retirar y reordenar desde instancia sin detach. No fijar11 como cardinalidad. El host mantiene exactamente una página selected, orden coherente y extremos/ellipsis; Figma no ejecuta ese algoritmo automáticamente. Vacío es inválido: si no hay paginación aplicable, el host retira el contenedor.

### REQ-LAYOUT

Preservar muestra default552×72 y compact213×72. Padding top16, lados24 e inferior24; gap default24 y compact12. Default Pages mide392 con11ítems de muestra y el Input88. Altura HUG y ancho HUG, sin wrapping automático. Rango oculto inicialmente preserva geometría. Para pie de tabla, el host establece ancho disponible y distribución space-between; no prometer centro geométrico exacto ni compact automático por breakpoint. Idiomas/texto largo pueden aumentar el ancho.

### REQ-TYPOGRAPHY

Page label usa Manrope Medium14/20; Range derivado usa Regular14/20 y texto secundario, tracking0. Aplicar dos estilos propios compartidos, con bindings; copiar estos roles no mueve la tipografía de Input/Item a tokens del padre. Las cadenas inglesas fuente son editables; muestras localizadas no cambian la API.

### REQ-TOKENS

Todos los tokens se agrupan en pagination/ con calificador group- en el último rol para evitar colisiones, conservando categorías color/bg, color/text, font, spacing y size. BH-P07 es el propietario de las reglas de mínimo/scope/colecciones.

### REQ-THEME

Todos los roles propios del contenedor son invariantes y repiten alias en los cuatro modos. La selección temática pertenece exclusivamente a Pagination item; Input conserva su propio contrato. El contenedor selecciona el modo component que heredan sus hijos. No añadir temas o modos para páginas o estados.

### REQ-CONTENT

Usar en listados con más de una página; no combinar con scroll infinito. Conservar filtros/orden al cambiar página y devolver foco al inicio del listado son responsabilidades del host futuro, no efectos nativos demostrados por estos componentes.

### REQ-BEHAVIOR

Default se recomienda para puntero fino y compact para interacción táctil; la elección no depende automáticamente del breakpoint. El host mantiene primera/última, vecinos y ellipsis cuando hay más de7páginas; flechas dobles simples se deshabilitan en extremos. No deshabilitar toda la paginación. Changing rows puede reiniciar la página en la muestra, pero el componente no contiene negocio ni un motor de consultas. Construir enlaces reales de reproducción con datos ficticios, distinguiéndolos de la lógica de datos.

### REQ-ACCESSIBILITY

No acreditar accesibilidad web ni interacción táctil física por capturas o ratón.
