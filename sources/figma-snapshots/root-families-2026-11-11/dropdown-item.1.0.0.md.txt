# DROPDOWN-ITEM-001 · dropdown-item 1.0.0

### REQ-SCOPE

Construir Dropdown item en la página Dropdown de Blue Heart DS. El origen y el proyecto anterior son solo lectura. Una única matriz observada de25 variantes, con sus assets, tokens y ejemplos; no crear una variante por icono ni completar combinaciones ausentes.

### REQ-API

API: type option/header/divider, size large/medium/small, state default/hover/focus/disabled, selected false/true. Matriz legal: option tiene false en los cuatro estados y true solo en default/hover/focus, para los tres tamaños (21); header solo default/false en los tres tamaños (3); divider solo medium/default/false (1). No hay selected/disabled ni otros estados de header/divider. Label, Description, Group label son TEXT; Show description y Show left icon BOOLEAN false; Left icon INSTANCE_SWAP con ImageSquare Outline/Light inicial. Default option/large/default/false, Label Option. La matriz legal prevalece sobre el producto cartesiano de las opciones de cada eje; consumidores validan antes de seleccionar una combinación.

### REQ-ANATOMY

Option contiene Left icon opcional, Content vertical con Label y Description opcional, Check solo seleccionado y Focus ring en focus. Header contiene Label ligado a Group label. Divider contiene Line. No hay Slot dentro del item: la variabilidad de la lista pertenece al menú. ImageSquare y Check son Phosphor Outline/Light vinculados, con sus keys fuente; no copiar vectores locales. El default de Left icon se conserva; permitir swaps de la biblioteca con color/tamaño del consumidor. Los30 fondos invisibles de contenedores Phosphor no renderizan y se omiten sin crear tokens.

### REQ-LAYOUT

Option: HORIZONTAL, ancho280 de muestra adaptable, HUG vertical, mínimo48/40/32 para large/medium/small. Padding horizontal12; vertical12/8/4; gap8, radio4, alineación MIN/CENTER. Content VERTICAL FILL/HUG, padding/gap0, clipsContent observado. Label HEIGHT/FILL/HUG sin truncamiento ni límite de líneas. Description conserva Manrope12/16 y se adapta a FILL/HUG, corrigiendo el ancho fijo residual228/200/232/208 de los nodos fuente para no recortar contenido en hosts estrechos. La altura crece con ambos textos y no queda fijada al mínimo. Header: padding superior12/inferior4/horizontal12, alto32 corto; tres variantes de size iguales, preservadas como API fuente. Divider: padding vertical4/horizontal0, Line FILL con altura1; alto9. Focus ring absoluto x=y=0, STRETCH en ambos ejes, borde interior2/radio4; se adapta al crecimiento del item, sin outset ni clipping por el ejemplo.

### REQ-TYPOGRAPHY

Manrope: Label large16/24, medium/small14/20; Regular no seleccionado y SemiBold seleccionado. Description12/16 Regular; Group label12/16 SemiBold. Tracking0 PIXELS. Aplicar seis estilos compartidos dropdown/item/large-regular, large-selected, compact-regular, compact-selected, description y group-label, con sus cinco bindings tipográficos. La variable portable conserva Semibold; Figma normaliza la cara a SemiBold, que debe estar disponible. No convertir la apariencia a una fuente aproximada ni conservar el estilo sin sus bindings.

### REQ-THEME

Fondo seleccionado default/focus, Label seleccionado e indicadores seleccionados siguen los vectores fuente de los cuatro temas. El texto seleccionado de Servicios usa el semántico strong observado. Hover usa fondo neutral fijo aun seleccionado. Foco es brand-strong Contable fijo en todos los temas; textos primary/description/group/disabled y fondos no seleccionados son invariantes. Divider usa el vector de color/border/subtle fuente, mediante FRAME_FILL de Line. No deducir un comportamiento temático global desde un solo color. Aliases y valores pertenecen exclusivamente al token set.

### REQ-ICON-COLOR

Consumir BH-P06 REQ-P06-03/04. ImageSquare/Check siguen Label por estado y tema, con SHAPE_FILL y aliases idénticos al TEXT_FILL correspondiente. Esto corrige el secondary de Left icon small no seleccionado y el color de marca distinto de Check/Left icon en Servicios seleccionado. Conservar key, peso y tamaño20 para large/medium,16 para small; la geometría del dibujo escala con el contenedor. No recolorear el maestro remoto. Desarrollo futuro consume ImageSquareIcon y CheckIcon weight=light de la distribución oficial.

### REQ-TOKENS

Aplicar BH-P07:34 firmas propias de Dropdown item, sin redundancias, bajo dropdown/ en component; rutas en la tabla. Compartir valores entre estados y tamaños solo por tipo, scope y aliases completos. Width280 es una muestra; no se crea un token de ancho fijo. Las propiedades derivadas/inertes no justifican variables ficticias. No fusionar estos tokens con los del menú ni con Input. Todos los modos y WEB están en el conjunto seleccionado.

### REQ-FUNCTION

Una option representa una elección; header y divider organizan contenido y no son interactivos. En selección simple el host conserva como máximo una option selected; selected muestra Check, SemiBold y color, no solo color. Disabled no elige ni recibe la acción del demo. El item no conoce el Input, los datos fiscales ni otras filas; el controlador de la composición actualiza el valor y cierra el menú. No inferir selección múltiple, búsqueda, validación, destinos o catálogo real desde Option/Description.

### REQ-CONTENT

Usar etiquetas y descripciones contextuales en sentence case; Description puede aportar información complementaria, como RFC bajo razón social, sin sustituir el nombre de la opción. Group label rotula la categoría. Las cadenas fiscales de la muestra son contenido de ejemplo, sin validación fiscal ni destinos legales. Probar textos cortos, largos, vacíos y no divisibles; el texto vacío no acredita un nombre accesible válido.

### REQ-A11Y

El host web implementa role=option, aria-selected, aria-disabled, nombre accesible, foco y navegación por teclado según su listbox. Header/divider no son opciones seleccionables. Figma no acredita ARIA ni teclado. La decisión humana conserva Description por debajo de4.5:1 en hover (aprox4.34) y en algunos fondos seleccionados (mínimo aprox4.26); medir cada caso y documentar sin afirmar AA. Disabled es inactivo y no acredita AA. La limitación se restringe a estas partes/estados, no se transfiere a otras familias.

### REQ-PROTOTYPE

Las25 variantes fuente no tienen reacciones. El destino puede añadir únicamente default↔hover para option conservando selected y size; disabled/header/divider permanecen inertes. La elección única y la actualización del Input se prueban en una composición consumidora de ejemplo, sin hacer que cada option alterne de forma independiente ni prometer captura o teclado. Distinguir grafo almacenado de reproducción visible en el presentador.

### REQ-QA

Probar las25 combinaciones legales en cuatro modos; Show description/left icon y swaps, contenido largo y ancho reducido, alturas mínimas, crecimiento, radii, foco y paridad de iconos con Label. Contrastar cada binding, estilo compartido, alias y scope con la receta; probar selección en un menú consumidor y preservar las restricciones de la matriz. No acreditar diseño mediante pruebas del núcleo.
