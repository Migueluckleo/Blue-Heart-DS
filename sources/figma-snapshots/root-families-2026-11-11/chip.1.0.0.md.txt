### REQ-API

API pública: Label TEXT Label, Counter TEXT 12, Show counter/Show remove/Show left icon/Show right icon BOOLEAN false y Left icon/Right icon INSTANCE_SWAP PlusCircle Outline/Light. Los1512 candidatos preferredValues observados por swap se registran como cantidad en la evidencia; son sugerencias, no otra matriz de variantes. El destino conserva INSTANCE_SWAP y default Phosphor con lista preferida vacía, sin importar masivamente candidatos no usados. La partición nativa por tamaño produce cuatro sets Chip/large, Chip/medium, Chip/small y Chip/extra-small, diez variantes por set; cada set conserva size con su único valor, selected y state. El consumo lógico CHIP-001 resuelve size al set correcto y mapea propiedades por keys reales; no simular un único set ni añadir tamaños.

### REQ-ANATOMY

Anatomía horizontal: Left icon?, Label, Counter?(Count), Right icon?, Remove? y Focus ring absoluto solo en focus. Contador y Remove son partes propias, no instancias de Badge/Dot. No hay región de contenido extensible: TEXT/BOOLEAN/INSTANCE_SWAP cubren la variación; no se justifica Slot ni componente público Chip group por esta muestra.

### REQ-LAYOUT

Conservar altura fija48/40/32/24 y ancho HUG, radiofull, centrado y métricas/bindings fuente de la receta. Permitir crecimiento con contenido largo; el host agrupa con wrap o scroll horizontal, sin encoger la tipografía ni fijar un ancho global. No afirmar adaptación automática a hosts más estrechos que el contenido.
