# RADIO-GROUP-0011.0.0

### REQ-ANATOMY

Cuatro combinaciones direction=vertical/horizontal × state=default/error. Root vertical contiene Title, Options y Helper text. Las opciones son instancias oficiales RADIO-001@1.0.0, nunca otra implementación privada de Circle/Dot/Label.

### REQ-API

Por elección humana, exponer un único Options SLOT para ambas direcciones y conservar contenido/orden/propiedades al cambiar direction y state. Mantener Title/Show title, Helper text/Show helper text. Title inicia Label; ambos flags true. Por elección humana, Helper text controla los caracteres solo en default. En error conservar Select an option fijo y sin referencia characters a esa propiedad; Show helper text aplica a ambos estados. La propiedad global sigue existiendo en error, pero editarla no cambia el mensaje visible. Un mensaje contextual adicional pertenece al host y no se presenta como una capacidad de este componente. Guardar keys reales después de combine, sin conservar Options2 como API actual del destino.

### REQ-SLOT

Options nativo acepta solo instancias de Radio, mínimo2 y máximo5 por propiedad común. Horizontal admite como máximo3 opciones cortas: ese límite específico pertenece al contrato y al guard/QA del consumidor, porque el Slot común no posee límites por variante. Probar2/5vertical,2/3horizontal, rechazo de0/1/6, tipo ajeno y4horizontal por validación del consumidor. No atribuir un error nativo ABOVE_MAX a4horizontal si el límite común5 no lo produce.

### REQ-COMPOSITION

Las doce opciones de muestra mantienen pin exacto a RADIO-0011.0.0. Cada opción insertada aporta Label no vacío y Show label=true; el host mantiene selección exclusiva, selected/disabled y orden. Default fuente muestra tres opciones, primera seleccionada; error muestra tres sin seleccionar con state=error. La muestra de3 no fija cardinalidad. No copiar tokens o estilos internos del hijo ni introducir dependencia de Dot público.

### REQ-LAYOUT

Root HUG en ambos ejes, padding0/gap8, alineación MIN. Options vertical usa gap8 y horizontal24, HUG y sin wrap automático. Conservar muestras87×144defaultvertical,91×144errorvertical y307×80horizontal. Etiquetas largas o idiomas pueden aumentar alto/ancho; elegir vertical o ancho suficiente. No prometer responsive automático ni recortar el texto para sostener las medidas de muestra.

### REQ-TYPOGRAPHY

Title Manrope SemiBold14/24 y Helper Regular12/16, tracking0, dos estilos propios con bindings. La cadena Foundation Semibold se presenta como SemiBold nativo; conservar alias y verificar el estilo real, sin cambiar la Foundation. Title es fijo primary, Helper secondary por defecto y danger en error. Las opciones conservan tipografía de Radio.

### REQ-TOKENS

Catorce firmas para88usos propios bajo radio/ en component, con group- en el último calificador cuando separa responsabilidad. Aplicar BH-P07, sin Foundations nuevas ni duplicación de tokens hijos. Todos los roles propios del grupo son invariantes y repiten alias en cuatro modos; los hijos heredan el tema component del contenedor.

### REQ-CONTENT

Usar opciones paralelas y sentence case con título que explique la decisión; ejemplos LATAM PUE/PPD y Persona física/Persona moral no son reglas de negocio. De2a5opciones, más de5 requiere otro patrón del host. No mezclar radios y checkboxes ni usar un radio aislado como booleano. Preseleccionar solo cuando el host tenga una recomendación segura; el default visual de muestra no autoriza selección de negocio.

### REQ-BEHAVIOR

El host conserva un único valor y como máximo una opción selected; error inicial puede estar vacío. Al seleccionar una opción se mantienen las demás deseleccionadas; pulsar la actual no borra el valor y disabled es inerte. La validación/error y su limpieza son del host. El componente de grupo no contiene un algoritmo que sincronice automáticamente sus instancias: demostrar selección exclusiva con prototipo de datos ficticios y registrar ese límite.

### REQ-ACCESSIBILITY

Consumo web futuro: radiogroup con aria-labelledby al título, ayuda/error por aria-describedby e invalidez cuando corresponda; conservar reglas de Radio. Si se oculta Title/Helper, el host aporta nombre/explicación equivalentes cuando necesarios. No acreditar ARIA, teclado ni servicios por la reproducción con ratón. El host táctil amplía áreas24 a44sin alterar silenciosamente el principal.
